# SKILL: Expansion Part 2 - Forensic Premise Decomposition

## Mandate & Directive
Break down each individual argument, vignette, and evidentiary example in the section (e.g. court cases, historical events, technical reports). 

For each premise:
1. **Manuscript Basis**: State the exact textual assertion, vignette, or quote.
2. **Anchor Quote Identification (BILGELADLE-RULE-001)**: Cite the specific human expert (e.g., Leval, Madison, Frost, Samuelson, Eco, Wittgenstein) and unpack why their statement is an epistemic backstop.
3. **Forensic Breakdown**: Unpack the philosophical, computational, and institutional mechanisms at play.

## Formatting Template
```markdown
### Premise 1: [Descriptive Name of Premise]
* **Manuscript Basis:** [Direct reference to section text / event]
* **Anchor Quote:** "[Quote]" — [Author] ([Year])
* **Forensic Breakdown:** [Rigorous analytical decomposition]
```
