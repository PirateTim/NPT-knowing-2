# Technical Design Document: Structural Topology## 1. Directory Blueprint LayoutThe project tree enforces strict namespace isolation to prevent module drift:* `src/react_agent/` - Core gateway orchestration runners.* `src/react_agent/agents/` - Reserved exclusively for XML Crew Profile Manifests.* `src/react_agent/tools/` - Reserved for stateless python system tool wires.## 2. Automated Lineage TrackingUpon processing a backlog milestone or completing a folder compilation layout pass, the active agent profile must dynamically execute `post_github_comment` to record a structural footprint trace directly back to the active issue ID.
